# 远端快照与共享

## 设计结论

浏览器和主服务的会话读取路径消费已发布的本地快照。模块将远端内容放入私有暂存目录，验证来源身份、归档结构、允许文件集和资源预算后原子发布为当前快照。共享端以独立 HTTP 服务提供受限的快照归档和历史索引。

## 要解决的问题

远端会话可在传输期间改变，也可能包含超限、越界或未允许内容。远端地址变更会使已有快照失去当前来源资格。工作台通过紧凑索引定位较早会话，并由认证边界保护共享记录。

## 核心模型

- 本机配置存储持有连接元数据和仅本地保存的令牌；浏览器来源响应、日志错误和快照元数据使用移除令牌后的视图。
- 每个远端定义计算来源版本，并拥有自己的私有快照根。来源证明匹配当前版本时，快照进入可读状态；不匹配时进入待刷新状态。
- 刷新操作按“共享订阅、并发闸门、私有暂存、验证、代际发布、清理”的顺序执行。发布时在快照根的提交协调器内做最终来源检查和 `current` 指针替换。
- 快照只允许会话 JSONL、线程数据库、会话索引和产品元数据。归档解压还限制路径类型、重复路径、传输/解压字节数和文件数。
- 共享服务单独认证健康、归档和索引端点。索引优先受限 SQLite 查询，并以受预算限制的文件扫描补全；响应返回紧凑会话元数据。

## 与现有模块的交互

主服务通过数据源注册表刷新并切换远端来源，通过受期限和取消信号保护的 HTTP 客户端访问共享服务。会话读取模块使用通过来源围栏的 `current` 快照；任务归档模块从其中的可读会话提取任务。历史索引承担定位职责，正文由已发布快照提供。

## 必须保持的规则

- 当前快照指针仅在暂存与验证完成后替换。刷新失败时，仍与当前来源匹配的既有快照保持可读。
- 快照验证将允许内容、归档路径和资源预算统一为发布前门槛。
- 来源证明与配置来源版本不一致时，快照进入待刷新状态。
- 远端配置和快照存储采用私有权限；浏览器来源视图和面向用户的错误不包含令牌。
- 快照共享服务由令牌保护；认证方式和端点约定见[实现参考](../implementation.md)。

## 交付边界

模块负责受限传输、本地私有发布和共享接口。远端账户身份供应、TLS 终止、网络拓扑、数据保留和备份由运行环境负责。

## 实现定位

- `src/renderer-config.mjs` 管理私有远端连接定义与公开视图。
- `src/data-sources.mjs` 负责来源版本、刷新、归档验证、私有权限和快照发布。
- `src/remote-http.mjs`、`src/snapshot-budget.mjs` 与 `src/snapshot-root-commit-coordinator.mjs` 提供传输取消、资源预算和原子提交协作。
- `share-server.mjs` 与 `src/snapshot-share.mjs` 装配并实现受认证的共享端点，`src/remote-session-index.mjs` 负责历史索引文件回退。
