# 远端快照与共享

## 设计结论

远端会话不直接暴露给浏览器。工作台将远端内容先复制或下载到私有暂存目录，确认来源身份、允许文件集和资源限制后原子发布为当前本地快照。另一端的共享服务只按受令牌保护的 HTTP 接口提供受限快照归档、历史索引和健康状态。

## 要解决的问题

远端会话可能同时更新、体积过大、包含未允许的归档条目或在配置变更后不再属于原来的来源。系统需要让读取端只看见完整且同源的版本，同时让共享端不会在无认证的情况下泄露会话数据。

## 核心模型

- 数据源注册表根据环境变量和本地配置建立远端定义，并为每个定义计算来源版本和私有快照根。
- 刷新操作使用共享订阅与全局并发门限，先在暂存目录获取数据，再验证快照结构、大小、文件数量与来源身份，最后发布当前版本。
- 已发布快照只允许 Codex 状态数据库、索引、会话 JSONL 和产品元数据。Unix 上目录和文件分别收紧为私有权限。
- 共享服务为快照归档、索引和健康检查逐一执行 Bearer 令牌验证，归档构建也受输入、输出、文件数、时限和队列约束。

## 与现有模块的交互

主服务通过数据源注册表管理远端来源，并用 `remote-http` 的时限和取消信号访问远端共享服务。快照共享服务重用数据源的允许文件和索引语义，但不提供会话浏览界面。会话读取模块只消费当前且通过来源围栏的快照。

## 必须保持的规则

- 远端来源刷新完成前，暂存数据不得替换当前快照。
- 快照来源配置改变后，旧快照不能继续作为当前来源读取。
- 不在允许集合中的文件、重复或不安全的归档路径，以及超过资源上限的响应必须被拒绝。
- 共享服务没有令牌时不得启动，受保护端点不得接受缺失或不匹配的 Bearer 令牌。

## 交付边界

本模块负责会话快照的安全传输、存储和共享，不负责远端身份供应、网络部署或长期备份策略。远端地址和访问令牌由运行环境或本机配置提供，代码不会把令牌返回给浏览器。

## 实现定位

- `src/data-sources.mjs` 中的 `createDataSourceRegistry`、`refreshRemoteSource`、`validateSnapshot` 和 `publishSnapshot` 负责来源、刷新与发布。
- `src/snapshot-share.mjs` 中的 `createSnapshotShareHandler`、`createSnapshotArchive` 和 `createSessionIndex` 实现共享 API。
- `share-server.mjs` 拒绝缺少 `CODEX_SHARE_TOKEN` 的启动，并装配共享 HTTP 服务。
- `src/access-control.mjs` 和 `server.mjs` 对主服务非 loopback 监听应用访问令牌要求。
