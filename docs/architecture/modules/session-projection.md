# 会话读取与投影

## 设计结论

该模块采用“来源隔离、验证读取、纯投影”的设计。主服务只负责将 HTTP 请求编排到来源上下文；读取、规范化、查询和展示模型只把 JSONL 与 SQLite 元数据转换为响应数据，不修改原始会话，也不把摘要当作会话事实的替代品。

## 要解决的问题

Codex、Pi Agent 和已发布远端快照的文件布局、索引能力与事件形态不同。会话文件还可能在列表或详情读取期间持续写入。模块为各来源提供稳定的列表、详情、事件诊断、执行过程、时间统计和 Markdown，并将变化中的会话标记为非完整读取状态。

## 核心模型

- 数据源上下文拥有来源身份、可读根、SQLite 线程存储、短期目录缓存、详情协调器和任务归档协调器。远端上下文只能使用当前且来源版本匹配的私有快照。
- 目录发现以索引元数据和 JSONL 文件相互补全。Pi Agent 直接使用文件发现；同 ID 的活动和存档文件按活动优先及更新时间去重。Pi 会话首部的 `parentSession` 被解析为 `parentSessionId` 并暴露到列表与详情投影，供前端展示分叉链；父会话不存在时链在孤儿节点断开，不虚构节点。详情的 `related` 字段附带父、子和祖先链摘要，链遍历有环检测和深度上限。
- 规范化层把异构原始事件转换为稳定内部模型；事件层由此构建轮次、工具调用、执行树、子代理关系和诊断摘要，时间层计算可确认的等待输入、实际运行区间与并行构成。
- 详情协调器以来源、会话、读取视图和文件签名作为共享读取与缓存边界。读取开始和派生完成后文件签名不一致时，以变化中状态返回。

## 与现有模块的交互

远端模块提供来源定义、当前快照及其来源围栏，会话模块只在其可读边界内读取。任务归档模块复用同一来源上下文和读取闸门，但自己拥有归档的有界提取、缓存和取消语义。浏览器由 `public/` 负责以紧凑工作目录树中的会话叶子和正文为默认阅读面，目录折叠状态按来源隔离且仅保留在当前浏览器会话中，搜索和当前会话路径自动展开；同一主工作区提供正文、执行、诊断三视图，其中执行、统计、Raw 与工具详情仅在对应视图显示；访问控制和 HTTP 错误映射由主服务及响应模块负责。

## 必须保持的规则

- 原始 Codex 与 Pi Agent 会话只读。浏览、搜索、Raw、Markdown 和导出均从读取结果派生。
- 所有公开投影都携带来源身份；不同来源中的同名会话不得共用缓存或相互覆盖。
- 远端会话、索引和数据库只从当前已发布的验证快照读取；不满足快照边界的输入视为不可读。
- 完整详情和缓存只接受读取前后签名一致的文件版本；取消和读取失败不产生稳定缓存。
- 缺少完整边界的事件不得伪装为精确运行时间。分类区间允许重叠，但实际运行时长按区间并集计算。
- 分叉链只表示 Pi 会话首部的 `parentSession` 事实，不与 Codex 的 `thread_spawn` 子代理关系混用；两者语义、来源与展示分层不同。

## 交付边界

远端下载和连接定义由远端快照模块负责，浏览器布局与交互由 `public/` 负责。原始事件字段、控制包处理和兼容 profile 由[事件规范化契约](../../session-event-normalization.md)完整说明。

## 实现定位

- `server.mjs` 的来源上下文、目录、详情、事件和 Markdown 路由负责请求级编排。
- `src/session-catalog.mjs`、`src/sqlite-threads.mjs` 和 `src/jsonl-reader.mjs` 负责候选发现、索引读取和 JSONL 读取。
- `src/session-normalizer.mjs`、`src/session-events.mjs`、`src/embedded-subagents.mjs` 与 `src/session-timing.mjs` 负责稳定事件及其阅读投影。
- `src/session-detail-coordinator.mjs` 负责详情共享读取、文件签名校验、取消和 LRU 缓存。
