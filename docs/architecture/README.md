# Codex 会话工作台架构

## 目的

Codex 会话工作台把 Codex 与 Pi Agent 写入 JSONL 的会话记录投影为会话目录、详情、执行过程、时间统计、原始事件和任务归档，帮助读者理解一次 agent 执行中发生的输入、回复、工具调用和子代理活动。

摘要、标题和统计服务于阅读与检索，原始记录保留为诊断事实来源。会话内容的正确性、安全性、风险和缺陷归因由会话外的证据与审查流程判断。

## 系统边界

系统读取本机 Codex Home、可选 Pi Agent 会话根，以及已发布到本机私有目录的远端 Codex 快照。原始会话文件保持不变。

远端连接定义和远端快照属于工作台的本地派生状态，与会话来源隔离。主 HTTP 服务默认只监听 loopback；非 loopback 监听要求令牌认证。快照共享服务独立运行并要求令牌认证。

远端身份供应、TLS 部署、网络隔离、数据保留和备份由运行环境负责。

## 主要责任单元

- [会话读取与投影](modules/session-projection.md)：发现可读会话，建立来源隔离上下文，将 JSONL 和 SQLite 元数据投影为浏览器所需的列表、详情、事件、执行过程、时间统计和 Markdown。
- [任务归档与目标投影](modules/prompt-archive-and-goal-projection.md)：从稳定会话中有界提取首个有效用户任务，并对已验证的 Codex/Pi Goal 控制包失败关闭地投影目标文本。
- [远端快照与共享](modules/remote-snapshot-sharing.md)：管理受保护的远端定义、快照刷新和发布，以及供历史定位使用的受认证索引与快照共享。
- [实现参考](implementation.md)：提供 HTTP 装配、源码入口、运行时配置类别和测试映射；事件字段和兼容 profile 由[事件规范化契约](../session-event-normalization.md)负责。

## 核心流程

### 浏览会话

1. 主服务建立本机、可选 Pi Agent 和远端来源的数据上下文。Pi Agent 会话根可用时成为默认来源，否则使用本机 Codex。
2. 会话模块从可读来源建立目录，并将稳定会话派生为详情、执行过程、统计和 Markdown。变化中的会话返回明确读取状态。
3. 浏览器消费会话投影和按需诊断接口；Raw 与单事件接口提供完整原始记录。

### 归档任务

1. 任务归档从来源和范围确定候选会话，并为每个候选建立独立、可取消的读取订阅。
2. 协调器在固定文件、事件和正文预算内读取首段 JSONL，再次确认签名后提取第一个有效用户任务。
3. 未找到任务、文件变化、超出预算或读取失败都以明确状态返回。受限或变化中的内容不进入归档正文，也不作为缓存结果。

### 刷新远端来源

1. 主服务按当前来源版本启动远端刷新。
2. 刷新在私有暂存区获取内容，完成完整性和同源性验证后发布新的当前快照。
3. 刷新未完成时，当前同源快照继续提供读取；来源版本变化时，读取路径等待新快照发布。
4. 历史会话通过共享端索引定位，详情读取使用已发布快照中的正文。
